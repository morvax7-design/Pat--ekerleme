# Pat Pat Şekerleme 🍬

**Pat Pat Şekerleme**, klasik "match-3" (üçlü eşleştirme) mekaniklerine sahip, tamamen tarayıcı tabanlı ve eğlenceli bir bulmaca oyunudur. Web teknolojileri (HTML, CSS, JavaScript) kullanılarak geliştirilmiştir.

## 🎮 Oyun Hakkında
Bu proje, Candy Crush gibi popüler eşleştirme oyunlarının temel mantığını, modern web standartlarıyla birleştirerek sunmayı amaçlar.

### Öne Çıkan Özellikler:
*   **Dinamik Seviye Sistemi:** Her seviyede zorluk derecesi ve hedef skorlar otomatik olarak güncellenir.
*   **Özel Taş Mekanikleri:** Çizgili şekerler, paketli şekerler ve "Renk Bombası" gibi özel eşleştirme komboları içerir.
*   **Mağaza Sistemi:** Oyun içi kazanılan "Şeker Paraları" ile farklı görsel temalar satın alınabilir.
*   **Dahili Ses Motoru:** Harici dosya bağımlılığı olmaksızın, Web Audio API ile programatik olarak sentezlenen oyun sesleri.
*   **İlerleme Kaydı:** `localStorage` sayesinde oyuncunun ilerlemesi ve kazandığı paralar kaydedilir.

## 🛠 Kullanılan Teknolojiler
*   **HTML5 & CSS3:** Arayüz, animasyonlar ve duyarlı (responsive) tasarım.
*   **Vanilla JavaScript:** Oyun mantığı, eşleştirme algoritması ve ses üretimi.
*   **Web Audio API:** Ses efektleri ve arka plan müziği için.

## 🚀 Nasıl Çalıştırılır?
Projeyi çalıştırmak için herhangi bir ek yazılıma ihtiyacınız yoktur. Sadece `candy_crush_style-1.html` dosyasını modern bir web tarayıcısında (Chrome, Firefox, Edge vb.) açmanız yeterlidir.

## 📈 Geliştirme Notları
*   Oyunun mobil uyumluluğu (`viewport` ayarları) sağlanmıştır.
*   Performans için animasyonlar CSS `@keyframes` ile yönetilmektedir.
